# Part signature

A labelled example in [`signature-library.json`](../learning/signature-library.json):

| Field | Meaning |
|---|---|
| `slot` | generic ontology slot (sides/axles collapsed: `closure.door`, `wheel`) |
| `model`, `family`, `key`, `source` | provenance (`binding`, `companion`, `paint`, `vocabulary`) |
| `lateral` | 0 = centreline … 1 = flank |
| `spanX` | width share (≈1 = both sides merged) |
| `height`, `longitudinal` | centre as fractions of the vehicle bbox (longitudinal 1 = +Z end) |
| `sizeY`, `sizeZ` | extents as fractions |
| `vertShare`, `opaque`, `tokens`, `merged` | extra evidence |
| `vector` | weighted numeric vector used by kNN |

The library also stores **priors**: `articulationPriors` per open group, `regionPriors` (in vehicle-
frame fractions, transferable across assets) and `frames` (native length × scale → metres).
Generated by `npm run brain:learn`; never edited by hand.
