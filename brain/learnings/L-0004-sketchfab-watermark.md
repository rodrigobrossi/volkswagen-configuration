# Store watermark plates are meshes

Sketchfab downloads may bake a licence plate as a mesh whose material is named like `2020-2025`.
Remove it by material-name pattern (not by node name). The learning tools drop it too — it had inflated
the 1968 learning frame to 5.15 m.
