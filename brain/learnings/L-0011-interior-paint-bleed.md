# Interior metal shares the body-paint material

The 1973 cabin has painted metal using the body-paint material (dark red base factor). Donated to
another host it rendered dark red regardless of the chosen colour. Clone + retint it to the host's
paint; the cabin floor and engine bay follow the SELECTED paint as well.
