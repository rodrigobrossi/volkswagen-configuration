# Interior metal shares the body-paint material

The 1973 cabin has painted metal using the body-paint material (dark red base factor). Donated to
another host it rendered dark red regardless of the chosen colour. Clone + retint it to the
SELECTED paint; the cabin floor follows the selected paint too (the engine bay deliberately keeps
the asset's original paint tint — [engine bay](../algorithms/engine-bay.md)).
