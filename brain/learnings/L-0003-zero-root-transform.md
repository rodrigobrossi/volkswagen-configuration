# Zero the isolated root's transform

A root isolated from a multi-object file keeps its offset inside that file (1968 "new" car: (2,0,0)).
It cancels out for the body, but hinges pick it up twice → doors displaced by ~(−2,0,0). Zero the
clone's position/quaternion/scale before measuring anything.
