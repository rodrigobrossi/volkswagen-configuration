# Nested axle nodes and lying L/R names

1980 `roue_1` (rear axle) is a CHILD of `roue` (front axle): a recursive walk blends both axles —
measure only direct mesh children. The 1968's "FL" wheel measures on −X: left/right comes from
geometry, never from names.
